# Call Drop — Mini App

Красивый Telegram Mini App для стейкинга подарков.

## Как запустить

1. Создай репозиторий на GitHub
2. Залей все файлы из этой папки (`index.html`, `style.css`, `app.js`)
3. Включи GitHub Pages (Settings → Pages → Deploy from branch `main`)
4. Скопируй ссылку вида `https://твой-ник.github.io/название-репо/`
5. Вставь эту ссылку в кнопку бота

## Файлы

- `index.html` — разметка
- `style.css` — стили (тёмная тема, адаптив)
- `app.js` — логика стейкинга + интеграция с Telegram WebApp

## Что уже есть

- Красивый интерфейс под Telegram
- Баланс и стейкинг
- Модальные окна
- Быстрые кнопки сумм
- Поддержка темы Telegram
- Имя пользователя из Telegram
